## Resolved versus narrowed gaps

**Resolved as static code contracts:** launcher stage concurrency and internal order, progress/status markers, after-launch hide trigger, cancellation wiring, selected exit classification, 113 setting registrations, selected profile/global validation differences, feature/HUD base signatures, typed setting interfaces and the JS↔Java UI bridge.

**Narrowed, not resolved:** complete compatibility solver; game settings payload/defaults; feature algorithms; native browser texture producer; current launch metadata; replay internals and service semantics.

A code-declared validation path is not evidence of every caller using it. In particular, global resolution validation and the inspected per-profile override setter differ. The RAM default table literal is overridden by a default method. These details matter when claiming parity; an independent product may choose a consistent policy instead.
