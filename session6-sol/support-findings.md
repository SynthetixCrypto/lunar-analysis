**Confirmed — S6-SUPPORT-02.** Ordinary setEnabled is not intrinsically the full toggle API: L._88f3cf._1e73d7._2ce426.setEnabled @0–13 writes its setting using _b03e9c. L._ec7e36._13ea87._1e73d7(T,boolean) updates the stored value @15–24, but suppresses normal observer delivery when an effective interceptor value is present @25–80. Thus setters can update remembered intent while an override masks effects. All 32 setter call instructions are preserved in the exact xref file; sources include server disconnect/restoration, Apollo StaffMod messages, UI/JS toggles, profile actions, feature callbacks, modern chunk-border mixins and OptiFine. Their concrete referenced method is the same setter, except wrappers can additionally apply locking semantics; no universal subscription-change claim is made for those calls.


**Confirmed — S6-SUPPORT-08 (terminology refinement).** The standard toggle implementation L._88f3cf._1e73d7._2ce426.isEnabled @0–15 calls its enabled setting.get(), which L._ec7e36._13ea87.get @0–39 resolves through interceptor Optional.orElse(rawStored). Prior descriptions that call isEnabled a stored toggle must retain this qualification. The raw stored value is the setting base accessor _1f5b06, not universally isEnabled.

## G-19 and G-22: reset, metadata omissions, and actual setting precedence

**Confirmed — S6-SUPPORT-03.** Generic settings do not use the feature Boolean EnumMap precedence. L._ec7e36._1e73d7._2ce426 has exactly one _a781fa holder. Its setter validates/coerces via setting._a9c329 @3–22; a successful non-null write unconditionally replaces holder category+value @79–86. There is no category comparison and no per-category stack. ## Implementation guidance and residual limits

Independent architecture should model raw option values, effective interceptor values, feature-selected overrides, handler desire/active subscription, lifecycle stage and dynamic allowance separately. The observed implementation uses different arbitration policies for feature booleans and generic settings; a shared priority map would not reproduce it. Full toggle handling is reached through conditional observers, which can be suppressed by masking or equality, then followed by recursive effective recomputation. Criteria definitions survive active reset; matching failure alone does not clear them.

G-18 is substantially resolved for directly referenced producer APIs and common lifecycle paths. Remaining limits: full per-source payload provenance, runtime reflection/plugins, actual producer ordering and per-instance decorator supplier state. G-19/G-22 static source arbitration and criteria reset are resolved within the enumerated interceptor implementations; remote deletion semantics outside the inspected processing paths remain unknown. G-21 successful local dependency transition order is resolved; live inter-producer ordering remains unknown.
